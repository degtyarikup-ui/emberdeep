# CLAUDE.md

Инструкции для этого репозитория живут в **[AGENTS.md](AGENTS.md)** — прочти его перед первой правкой.

Дополнительно обязателен **[SPRITE_COMPOSITION_RULES.md](SPRITE_COMPOSITION_RULES.md)** — 9 правил по графике, локализации и продакшен-безопасности.

Самое короткое, что стоит помнить всегда:

- `npm run build` (включает `tsc -b`) — единственная автоматическая проверка в проекте. Прогоняй перед коммитом, тестов и линтера здесь нет.
- Рантайм-ассеты только в `public/assets/` и только через `asset()` из `src/gfx/pack.ts`. Папка `vendor/` в сборку не попадает.
- Дебаг-меню создаётся исключительно через `isDebugAllowed()` (`src/debug/access.ts`) — на Яндексе его быть не должно.
- Новые строки интерфейса — сразу в оба словаря (RU и EN) в `src/i18n/index.ts`.

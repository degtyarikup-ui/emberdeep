# Emberdeep

Кооперативный рогалик-кроулер в 2D пиксель-арте, тёмное фэнтези. Соло или онлайн до 4 игроков.

**Играть:** https://degtyarikup-ui.github.io/emberdeep/

## Что внутри

Спуск по этажам подземелья: зачистка, сундуки и святилища, алтарь с боссом, лестница вниз. Смерть заканчивает забег, но накопленные «угли» тратятся на постоянные апгрейды у костра.

- Три класса: Рыцарь (ближний бой), Следопыт (лук), Волшебник (посох)
- Четыре биома, каждый со своей вёрсткой уровня и боссом
- Стихии и кросс-стихийные комбо (огонь + яд, лёд + молния и др.)
- Онлайн-кооп до 4 игроков по короткому коду комнаты
- Русский и английский интерфейс

Стек: Phaser 3.90 + TypeScript + Vite. Мультиплеер — Supabase Realtime. Звук синтезируется процедурно на Web Audio, аудиофайлов в проекте нет.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # линтер + тесты + сборка — прогнать перед коммитом
```

Пуш в `main` автоматически деплоит на GitHub Pages, но только если `check` зелёный.

## Ассеты

Графика собрана из бесплатных паков с открытыми лицензиями: Pixel Crawler (Anokolisa), 0x72 DungeonTilesetII, 32rogues. Полные исходники паков лежат в `vendor/` вместе с файлами лицензий; в сборку попадает только то, что скопировано в `public/assets/`.
